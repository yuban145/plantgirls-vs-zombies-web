# 网页版检查与修复（2026-11-15）

## 核对依据

本地原版 `PlantGirlsVsZombies/Content`、原版实机截图 `docs/reference` 与反编译 C#。没有更改原游戏目录。

关键来源：`Sexy/TodLib/Reanimation.cs` DrawTrack/GetTransformAtTime/DrawSpineGroup；`ReanimatorDefinition.cs` ExtractImages；`Lawn/Board.cs` DrawBackdrop/InitLevel；`Lawn/Plant.cs` Fire/GetPeaHeadOffset/UpdateBowling；`Lawn/Zombie.cs` UpdateAnimSpeed/UpdateZombiePolevaulter；`Lawn/SeedBank.cs` UpdateConveyorBelt；`Lawn/SeedPacket.cs` 初始冷却；`Lawn/Challenge.cs` CanPlantAt。

## 本轮修复

- 贴图导出 Color 使用 RGBA，恢复所有导出图集/图片的正确颜色。旧蓝色阳光板并非原版着色效果。
- Reanim 使用正确的部件原点；插值遵循原版缓存 sin/cos；包围盒计入缩放、旋转和隐藏层。小车散架、阳光分层错位得到修复。
- 普通僵尸朝左；步行动画依地面轨道和移动速度同步，啃食与寒冷同步动画速度；撑杆跑步、跳跃约 180 tick 后落地，不再 40 tick 截断。
- 植物娘使用 Spine WebGL，保留网格、裁剪、PMA 透明、物理约束，消除 Canvas 三角形接缝；原版固定缩放 `ISUI / mSpineScale = 1.25 / 16`。
- 1-1 单行、1-2/1-3 三行草坪，限制种植、僵尸出生排与小车；1-4 起五行。
- 玩家选择六张卡后开始战斗，选卡期间不推进波次；传送带恢复左侧竖向运动、卡片由下方进入。
- 1-5 使用原版 `_ground` 滚动动画/轨道速度，坚果撞击、斜向反弹、边缘折返、爆炸坚果，限制在红线左三列放置。
- 卡片名称/阳光价格、初始长冷却、原版按钮/菜单背景、枪口坐标；铲子点击范围覆盖图标，右键取消，操作说明可打开。
- 固定 100 Hz 主循环允许每帧补足最大 75 tick（0.25 秒 × 3 倍速），恢复低帧率倍速；隐藏页面停止累计，防止切回追赶。结算计时从绘制转到模拟。
- 铲除/被吃掉的双发射手取消未发出的第二发；关卡加载时防止重复点击开始。
